# Feedback Organizer

Organize review notes against a checklist of criteria — tag each point as a
strength or concern, and export a clean summary for every entry.

## Why it's laid out this way

The review grid is built to sit in a **short horizontal strip** across the top
of your screen, so you can keep your source material — a browser tab, a PDF, a
document — open underneath and **cross-check side by side without switching
windows.** Read on the bottom, tag on the top, scroll each the way it wants to
go. Columns and rows resize, and the criteria column stays frozen on the left
as you scan across entries, so nothing scrolls out of view while you compare.

## How it works

1. **Paste** your criteria (one per line) and each entry's notes.
2. **Match** — the tool lines each note up with a criterion as a starting point.
3. **Review** — confirm or adjust each match, tag it as a strength or concern,
   note a page reference, and score the entry.
4. **Export** — get a tidy strengths/concerns list per entry, ready to copy.
   

## No AI, no server

Everything runs locally in your browser. There's no AI model and no backend —
the auto-match is a simple keyword overlap that suggests where notes belong.
**Every judgment call stays with you:** whether a point is a strength or a
concern, which criterion it belongs to, what to ignore. Nothing you paste is
uploaded or stored.

## Use it

- **Live:** https://kl-sin.github.io/feedback-organizer/
- **Offline:** download `index.html` and open it in any browser.

## Features

- Auto-match suggests where notes belong; you confirm
- Tag each point as a strength or concern
- Frozen criteria column, resizable rows and columns
- Page references and per-entry scoring
- Side-by-side export with one-click copy
- Fully local — no accounts, no uploads
